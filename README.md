# برای مامان و بابا 💌

A Persian (RTL), mobile-first family tribute website built with plain HTML, CSS and JavaScript.

## Structure
- `index.html` - page markup
- `css/style.css` - styles (light/dark theme, animations)
- `js/app.js` - behavior; edit the `CONFIG` block at the top to change names, reasons, memories and wishes

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload these files to a new GitHub repository.
2. Go to Settings > Pages.
3. Under "Build and deployment" choose Branch: `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
